# DEFECT & PATCH LEDGER (DPL)
**Framework Engine:** Declarative Zero-Trust Synthesis Engine (v5.6)
**Purpose:** Cryptographic tracking of architectural friction and engine updates.

## [ENTRY 001] AADSTS50076 (invalid_grant) B2B MFA Block
* **Error / Symptom:** Global `az login` command triggered a multi-factor authentication block from a secondary federated B2B partner tenant, crashing the token retrieval process.
* **Root Cause:** The authentication request was unscoped, prompting Azure CLI to query all associated directories rather than just the target Identity Root.
* **Engineered Fix:** Appended `--tenant "<IAL_TENANT_ID>"` to the `az login` command to explicitly scope the authentication sequence to the primary directory, permanently suppressing foreign B2B exceptions.

## [ENTRY 002] Subject Claim String Interpolation Collision
* **Error / Symptom:** The Federated Identity Credential payload was successfully submitted, but the subject claim string silently dropped the repository ID and `ref:refs` segment (e.g., `iteration-10@/heads/main`).
* **Root Cause:** PowerShell misinterpreted the colon (`:`) immediately following the `$githubRepoId` variable as a scope modifier, evaluating to `$null` and corrupting the strict matching string required by Microsoft Graph.
* **Engineered Fix:** Enforced explicit bracket notation (`${githubRepoId}`) across the REST API payload generation block to securely isolate variables and guarantee structural integrity.

## [ENTRY 003] MSAL Deserialization Crash (Docker)
* **Error / Symptom:** The GitHub Actions runner failed with `AttributeError: Can't get attribute 'NormalizedResponse'` when executing the `azure/cli` action.
* **Root Cause:** A severe serialization conflict between the host OS OIDC token cache generated by `azure/login` and the Python `pickle` library inside the Azure CLI Docker container.
* **Engineered Fix:** Completely deprecated the `azure/cli` Docker action in favor of a native host OS `run` command block, sidestepping the containerized MSAL library conflict entirely while maintaining functionality.
